Про бэкенд

Бэкенд — это серверная часть приложения. Всё, что происходит "под капотом": обработка запросов, работа с базой данных, бизнес-логика, безопасность. Фронтенд рисует кнопки, бэкенд делает так, чтобы они работали.

Что я конкретно делаю

  • Проектирую и пишу REST API
  • Работаю с базами данных (модели, миграции, оптимизация запросов)
  • Реализую аутентификацию и авторизацию (JWT, сессии)
  • Пишу бизнес-логику — то, ради чего приложение вообще существует
  • Автоматизирую рутину через Bash и Linux-окружение
